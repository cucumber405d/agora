# 2026-11-10 — Mark files with the mouse

## RU
- **Что изменилось:** клик мышью точно по `[ ]` / `[x]` в панели файлов ставит или снимает отметку; клик по имени файла, как и раньше, только переводит курсор.
- **Зачем:** отмечать файлы можно было только клавишами `Space`/`Ins`.
- **Влияние:** подсчёт контекста обновляется сразу; управление с клавиатуры не изменилось.

## EN
- **What changed:** a mouse click exactly on `[ ]` / `[x]` in the file panel marks or unmarks the file; a click on the file name still only moves the cursor.
- **Why:** files could only be marked with `Space`/`Ins`.
- **Impact:** the context count updates immediately; keyboard control is unchanged.

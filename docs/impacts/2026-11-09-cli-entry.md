# 2026-11-09 — `agora` command

## RU
- **Что изменилось:** добавлена команда `agora [--config PATH] [--root PATH] [--version]`: загружает `.env`, проверяет конфигурацию и ключи, включает Langfuse (если настроен) и запускает TUI. Логи (и предупреждения Python) пишутся только в `~/.agora/logs/agora.log` (каталог меняется через `AGORA_HOME`, уровень — через `AGORA_LOG_LEVEL`).
- **Зачем:** единая точка входа; терминал во время работы TUI ничем не засоряется.
- **Влияние:** при ошибке в конфигурации или отсутствии нужного API-ключа приложение не стартует: сообщение с именем поля или переменной и код выхода 2. С конфигурацией по умолчанию критику нужен `ANTHROPIC_API_KEY`; для полностью локального режима задайте критику `provider: ollama`.

## EN
- **What changed:** added the `agora [--config PATH] [--root PATH] [--version]` command: it loads `.env`, validates configuration and keys, enables Langfuse (when configured) and starts the TUI. Logs (and Python warnings) go only to `~/.agora/logs/agora.log` (directory via `AGORA_HOME`, level via `AGORA_LOG_LEVEL`).
- **Why:** a single entry point; nothing clutters the terminal while the TUI runs.
- **Impact:** on a configuration error or a missing API key the app does not start: it prints the field or variable name and exits with code 2. With the default configuration the critic needs `ANTHROPIC_API_KEY`; for a fully local setup give the critic `provider: ollama`.
